# Changelog

## v1.0.0 — Final V1

First public release of OptiBlend.

Development builds were iterated internally through V1.23.1 before being frozen as the public v1.0.0 release.

### Included in Final V1

- Beginner, Intermediate and Advanced modes
- custom Q Helper with hover mini-tools
- animated/searchable Shapes and Materials shelves
- drag placement with glowing preview
- grid, surface and object-centre snapping
- rotation controls while placing geometry
- centred XYZ helper
- smarter Edit Mode snapping
- procedural material library + Blender colour wheel
- common modifier tools
- camera and rendering shortcuts
- compositor Glow / Glare helper
- scene scanning, cleanup and Auto Collections
- external FBX / OBJ / GLTF / GLB / STL import
- QuadriFlow / triangulation / subdivision-ready tools
- Mixamo readiness and topology audits
- advanced performance / pipeline helpers
- configurable OptiBlend UI scale
- development Test Lab on `L`

### Final polish

- public version metadata reset to `1.0.0`
- GitHub-ready README and licensing layout
- duplicate/repetitive development comments cleaned from the source
- Beginner side layout finalised around one main Outliner
- release limitations documented instead of presenting experimental checks as guaranteed
