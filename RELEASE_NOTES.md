# OptiBlend v1.0.0 — Final V1

This is the first public OptiBlend release.

OptiBlend is aimed at students and newer Blender users who want a clearer starting workflow, while still giving Intermediate and Advanced users access to faster modelling, scene and pipeline tools.

## Highlights

- Beginner / Intermediate / Advanced workflow modes
- `Q` Helper with custom hover mini-tools
- animated Shapes and Materials shelves
- drag-and-drop shape placement with glowing preview
- grid, surface and centre snapping
- centred XYZ helper
- procedural materials + Blender colour wheel
- common modifier shortcuts
- camera, image render, animation render and compositor glow tools
- scene scan, cleanup and Auto Collections
- FBX / OBJ / GLTF / GLB / STL import
- retopology and topology audit tools
- Mixamo readiness checks
- performance, FBX and collaboration helpers for Advanced mode
- `L` Test Lab for development / classroom testing

## Before installing

OptiBlend changes some workspace and editor-area state when switching modes. If your Blender startup file is heavily customised, test the add-on in a copy of your setup first.

The Advanced Mixamo score is a heuristic, not a guarantee of successful automatic rigging.

## Install

Download `OptiBlend_v1.0.0_FINAL_V1.zip`, install it from Blender's Add-ons preferences, enable OptiBlend, then press `Q` in the 3D Viewport.

See `README.md` for the full guide.
